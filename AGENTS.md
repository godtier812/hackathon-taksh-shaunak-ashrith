# AGENTS.md — MindTrace

## What this is
MindTrace is a voice check-in app for early speech markers of Alzheimer's/dementia.
- `frontend/` — Next.js 16 website (landing page + caregiver dashboard). This is what runs in the Base44 preview.
- `backend/` — Electron desktop app. Records/analyzes check-ins, serves a local API on `127.0.0.1:4317/api`. **Not started in the Base44 dev environment.**

## Running the website
```
docker compose -f docker-compose.base44.yml up -d --build
```
The Next.js dev server runs on port 3000 with live reload (Turbopack). Source is bind-mounted from `frontend/`; `node_modules` lives in a named volume so installs persist across restarts.

## Backend / demo data
The dashboard (`/dashboard`) tries to reach the desktop app's local API. When it's absent the site shows Margaret's demo record — no backend needed for the landing page or demo dashboard. The API contract is in `docs/website-integration.md`.

## Next.js version note
This is Next.js 16 — APIs may differ from older versions. The frontend `AGENTS.md` is regenerated by `next dev`; keep it committed.

## No external secrets
The frontend runs without any external credentials. No secrets are required to boot.
